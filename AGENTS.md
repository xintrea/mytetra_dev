# Общие правила

* Отвечай кратко, без повторения постановки задачи.
* Перед изменением кода найди связанные файлы и составь план не более чем из 5 пунктов.
* Не анализируй весь репозиторий повторно, если задача относится к конкретному модулю.
* Открывай только необходимые файлы.
* Не читай каталоги `build`, `.git`, `third_party` и `generated` без прямой необходимости.
* Не изменяй файлы вне области текущей задачи.
* Не выполняй массовое форматирование, переименование или рефакторинг без явного разрешения.
* Не добавляй новые зависимости без явного разрешения.
* Не создавай коммиты, не выполняй `push` и не открывай Pull Request без явной команды.
* Перед удалением файлов, сбросом изменений и другими потенциально разрушительными действиями запрашивай подтверждение.
* После изменений показывай краткое резюме, список изменённых файлов и результаты проверок.
* Не выводи полностью большие файлы; показывай только существенные фрагменты или `diff`.

# Правила проекта

* Язык проекта: C++.
* Текущая версия интерфейса: Qt 5.
* Целевая версия интерфейса: Qt 6.
* Система сборки: qmake.
* Не переводить проект на CMake без отдельной задачи.
* Не удалять поддержку RC5 до реализации и проверки миграции старых данных.
* Изменения криптографии выполнять отдельно от миграции на Qt 6.
* Запускать только тесты и проверки сборки, относящиеся к текущим изменениям.
